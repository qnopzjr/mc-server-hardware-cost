## 先搞清楚：插件服吃的是哪几样资源

Minecraft 的主线程是单线程跑 tick 的，20 TPS 这件事只跟单核性能挂钩。你装的插件越多，堆在主线程上的活儿越多——WorldEdit 一次 //set 刷一大片、几十个刷怪笼、成百上千的漏斗和红石元件，全是单核在扛。核心数多但频率低的机器，在这种场景里就是很难用。

内存方面，插件服一般 4G 起步，4 核 8G 是比较常见的舒适区。版本影响很大：雨云官方页面给的参考基准是，1.18+ 的消耗约为 1.16+ 的两倍、1.12.2 的三倍。同一台机器在 1.12.2 能带 20 人，换到 1.20 可能 8 个人就开始掉 TPS。

带宽这块，按常见的估算，原版端每位玩家大概要预留 1.5Mbps 上行。面板形态的游戏云上行是固定 50Mbps，对普通插件服够用，除非你要开基岩版并且人数很多。

还有一项经常被忽略：防御。插件服公开 IP 后被打、被扫端口是很日常的事，选机房时顺手看一眼防御规格，比事后折腾要省事。

## 面板服还是 VPS：插件服的选择标准

雨云游戏云分两种形态，官方文档里的对比更直接：

| 对比项 | VPS 游戏云 | 面板游戏云 |
| --- | --- | --- |
| 管理方式 | SSH / RDP / VNC | 面板控制台 |
| 系统权限 | 完整系统权限 | 无系统级登录权限 |
| 文件管理 | SFTP、系统工具或远程桌面 | 面板文件管理 / SFTP |

| 灵活度 | 高，可自定义环境与多服务部署 | 较低，适合标准游戏服场景 |
| 成本 | 按资源灵活配置 | 性价比较高 |
| 适合人群 | 需要高度自定义环境的用户 | 希望快速开服的用户 |

落到插件服上，判断很简单：单端、一个人玩或者跟朋友合开一个服，选面板，一键开服，文件管理和备份都在网页上点。如果你要开群组服——也就是用 BungeeCord、Waterfall 或 Velocity 做代理，前面挂大厅服、后面挂生存和空岛——面板形态撑不住，得用 VPS。要在服务端上跑 MCDR 之类的工具、或者需要装自定义 Java 环境，也是 VPS。

## 计费模式：动态还是固定

雨云游戏云有两种计费方式。固定计费按购买规格固定收取，适合常驻开服；动态计费是低基础月租加"CPU 电量"日结，系统每天赠送一定基础电量，CPU 使用率基准是 20%，低于这个值不算耗电，超出的部分才按电量结算，单价随 CPU 型号浮动。

选哪个看你的开服节奏：寒暑假天天开、玩家随时能进，选固定，不用担心某天红石机器全速运转导致账单上浮。只有周末晚上开两个小时的临时服，动态计费能省下不少。

有个坑要提醒：插件服即使没人上线，服务端也在跑 tick——刷怪、红石、区块加载都在消耗 CPU。所以别指望动态计费能省到接近零，它的优势在"闲时"而非"空载"。

## 从购买到插件生效：实际操作流程

1. 注册账号并绑定微信，把首月 5 折券拿到手。
2. 进控制台 → 云产品 → 游戏云 → 购买，选择面板或 VPS 形态、CPU 机型、核心数与内存、硬盘、地区、计费方式。
3. 面板形态：在管理页点"重装/切换游戏"，选服务端核心。面板里可一键选的核心包括 Arclight、Mohist、CatServer、Fabric 等，也可以选纯 Java / Linux 环境，自己上传核心。Forge 需要走纯环境自行上传。
4. 进入 MCSM 面板，找到实例点开启。首次启动会提示同意 EULA，去服务端配置文件里把 eula 改为是。
5. 配置 NAT 端口映射。Java 版默认 25565，基岩版默认 19132，映射出去后要用公网地址加映射端口的组合进服。面板形态共用公网 IP，一般可以开 15 条映射，单个插件服够用。
6. 装插件：用面板文件管理或 SFTP（FileZilla 这类客户端）把插件 jar 丢进 plugins 目录，重启实例。
7. 改 server.properties：视距别拉满，6 左右是比较稳的值；非正版服把在线验证关掉。
8. Java 版本要对上：1.17 及以上用 Java 17，1.20.5 之后的服务端需要 Java 21，1.16.5 及以下用 Java 8 或 11。版本不对服务端直接起不来。

面板服的自研面板支持 CPU 核心数升降级、可视化管理、备份和 MySQL，后期人数涨了直接在管理页加内存加核心，不用重新开服搬存档。

## 插件服最容易踩的几个坑

**视距拉满。** 视距 10 以上对单核是实打实的压力，玩家多的服把视距压到 6 左右，TPS 立刻稳一截，画质损失远小于卡顿带来的体验损失。

**核心数迷信。** 4 核低频率打不过 2 核高频率，插件服的瓶颈在主线程。

**拿 E5 开高版本大服。** E5-2666 v3 便宜，适合低版本小服和挂机，1.18+ 带十几个人会很吃力。

**内存分配乱写。** 启动参数里按比例分配（-XX:MaxRAMPercentage）比写死一个固定值更安全，写超过实际内存会被容器直接干掉。

**没做备份。** 面板带备份功能，开服第一天就该把自动备份开上，插件冲突炸档不是罕见事。
